# GBRHelper 説明書（仕様・動き・機能）

GatherBuddyReborn（GBR）の自動採集を便利にする Dalamud プラグインです。
GBR 本体には手を加えず、GBR の自動採集のリスト（Auto-Gather のプリセット）を作る・GBR の IPC で自動採集を止める／動かす、という形で補助します。

- 版：0.3.0.8
- 作者：ヌル
- 前身：GBR Venture Relay 0.2.2.0（ベンチャー回収だけのプラグイン）。改名して機能を足したものです
- コマンド：`/gbrhelper`（別名 `/gbh`）で画面を開く。`/gbrhelper now` で、次の採集の切れ目で回収へ向かう

---

## 1. 画面の作り

左に一覧、右にその中身が出ます。

| 左の一覧 | 中身 |
|---|---|
| 「GBR の画面を開く」ボタン | GBR のメイン画面を呼び出す（開いているときに押すと閉じる）。GBR が読み込まれていなければ押せません |
| **必要なプラグイン**（青い帯） | 使うプラグインと、いま使えるか（§2） |
| 機能 → GBR の日本語表示 | GBR の画面の英語を日本語で出す（§3） |
| 機能 → ベンチャー回収 | 自動採集中にベンチャーを回収して戻る（§4） |
| 機能 → ベンチャー未採取品の採取 | まだ採ったことのない品を GBR のリストにする（§5） |
| 機能 → 全素材の補充 | Lv 帯ごとに全部の品を N 個ずつ採るリストを作る（§6） |
| 機能 → 霊砂・クリスタル | 霊砂・クリスタルを目標の数まで、原料を採って精選する（§7） |
| 機能 → Crafting Listsから末端素材抽出 | Artisan の Crafting Lists の素材を GBR のリストにする（§8） |

各項目にマウスを乗せると、短い説明が出ます。

## 2. 必要なプラグイン

左の一覧の「必要なプラグイン」（青い帯）で、導入されているかを確かめられます。
足りないものがあると「必要なプラグイン（不足 N）」になり、GBR が無ければ橙、ほかが無ければ黄色の文字で出ます。
版の書かれていないプラグインや、読めないプラグインが入っていても、ほかのプラグインの状態は出します。

| プラグイン | どのくらい要るか | 使う機能 | 無いとき |
|---|---|---|---|
| GatherBuddy Reborn | **必須** | すべての機能 | 何も動きません |
| AutoRetainer | 機能によって必要 | ベンチャー回収 | 回収できるかを判断できず、回収もできません |
| Lifestream | 機能によって必要 | ベンチャー回収 | 宿屋の部屋へ帰れません |
| vnavmesh | 機能によって必要 | ベンチャー回収 | 部屋の中で呼び鈴まで歩けません |
| Allagan Tools | 機能によって必要 | 全素材の補充（希望所持数）・霊砂・クリスタル（リテイナーの数の表示） | リテイナーの持ち数を数えられません |
| Artisan | 機能によって必要 | Crafting Listsから末端素材抽出 | この機能だけ使えません |

状態は「導入済み（版）」「導入済み・停止中」「見つかりません」の 3 つで出ます。
見分けは各プラグインの内部名（`GatherBuddyReborn`・`AutoRetainer`・`Lifestream`・`vnavmesh`・`InventoryTools`・`Artisan`）で行います。

## 3. GBR の日本語表示

GBR のメイン画面（全部のタブ・子窓・吹き出し・選択欄の一覧を含む）の英語を、日本語で表示します。右側は「有効」のチェックだけです（既定は ON）。

**仕組み**

- cimgui の公開関数 25 個（文字・ボタン・チェックボックス・タブ・表の見出し・選択欄・メニューなど）をフックし、**GBR の窓の中で描かれるものだけ**を辞書で置き換えます。ほかのプラグインの画面には触りません
- GBR の窓の中かどうかは、いま描いている窓の積み重ね（`CurrentWindowStack`）に GBR のメイン窓（`###GatherBuddyMain`）があるかで決めます
- ボタンやタブの**内部 ID は元のまま**にします。訳の後ろに 4 バイトを足し、元のラベルと同じハッシュになるよう計算しています（ID が変わるとタブの並びが崩れ、ボタンの状態が別物になるため）
- 辞書は埋め込みの TSV（決まった文 1029 行・`{0}` を含むひな形 106 行）。書式指定（`%d` など）が英日で違う行は読み込みで弾きます
- 差し替えの途中で何か起きたら、元の引数のまま本物の関数を呼びます（GBR の画面は英語のまま動く）

## 4. ベンチャー回収

GBR の自動採集中に、リテイナーのベンチャーが回収できるようになったら、採集の切れ目で宿屋の部屋へ戻って回収し、自動採集に戻ります。

```
ベンチャーが回収できる（AutoRetainer に 5 秒ごとに聞く）
  → 採集ノードを取り終わるのを待つ（戦闘中・詠唱中・エリア移動中も待つ）
  → GBR の自動採集を OFF
  → 宿屋の部屋へ入る（Lifestream の宿屋機能）
  → 部屋の呼び鈴へ歩く（vnavmesh）→ 呼び鈴を開く → AutoRetainer が回収
  → リテイナーの画面を閉じる
  → GBR の自動採集を ON に戻す
```

**使い方**：右側の「有効」（既定 ON）を入れて、GBR の自動採集を ON にするだけです。
GBR の自動採集が OFF の間は何もしません（採集していないときに勝手に宿屋へ行くことはありません）。

**設定**

| 項目 | 既定 | 説明 |
|---|---|---|
| 帰還先の宿屋 | リムサ・ロミンサの宿屋 | 8 都市の宿屋か「自動（Lifestream に任せる）」。大エーテライトに行っていない都市は選べません |
| 回収したら自動採集へ戻る | ON | 切ると回収後そのまま止まります |
| 回収に失敗しても自動採集へ戻る | ON | 切ると失敗した時点で止まります |
| 失敗したあと再挑戦まで待つ時間 | 30 分 | 2 回目までは 2 分、3 回続いたらこの時間 |

**回収の結果の数え方**

| 呼び鈴での結果 | 数え方 |
|---|---|
| AutoRetainer が動き、回収できるものが無くなった | 成功（回収回数 +1） |
| 開いた時点で回収するものが無かった | 回収不要（回収回数は増やさない。2 分は次を試さない） |
| AutoRetainer が動き出さない・時間切れ・AutoRetainer が無い | 失敗 |

**安全のための決まり**

- 採集ノードを開いている間（`Gathering`・`ExecutingGatheringAction`）は抜けません。判定式は GBR 本体と同じです
- 他のワールドに居る間・コンテンツの中では回収に向かいません（失敗に数えない）
- 回収が動いている間、GBR の設定「Wait for AutoRetainer Multi-mode」を OFF に保ちます（ON だと GBR が自分で採集を止めて回収を取り合うため）
- 自分が GBR を ON／OFF した通知は数えて読み飛ばします（読み違えて回収をもう一度始めないため）
- Lifestream の作業を止めるのは、自分が頼んだ移動のときだけです
- 時間は「諦めるまでの上限」にだけ使い、次へ進むのは状態の変化を見てからです（決め打ちの待ち時間はありません）
- プラグインを止めるときに GBR・Lifestream・AutoRetainer を操作しません（更新しただけで相手が止まらないように）

## 5. ベンチャー未採取品の採取

リテイナーのベンチャーで品を依頼するには、本人がその品を一度採っている必要があります。
採取手帳で**まだ採っていない品**を、採掘・園芸 × Lv 帯（Lv1-10 〜 Lv91-100）ごとに GBR のリストにします。

**使い方**

1. 帯にチェックを入れる（チェックは保存されるだけで、GBR にはまだ書きません）
2. 下の「**Auto-Gatherに追加**」を押す → チェックした帯のリストを GBR に作る（または作り直す）
3. GBR の自動採集を ON にする

帯の横に「未採取 n件」「判定待ち n件」「伝承録待ち n件」が出ます。帯に乗せると品の一覧（入れない品は理由つき）が出ます。全部採った帯（伝承録が要る品だけが残った帯も）は暗く「採取完了」になり、GBR の自動採集が止まっているときにその帯のリストを消します（チェックは残ります）。あとで伝承録を読むと、数秒で白に戻り、リストも作り直します。

**入れる品・入れない品**

- 入れる：ベンチャーで依頼できる品のうち、採取手帳でまだ採っていない品。目標の数は「今の所持数＋1」（GBR はリストの数まで採るので、1 個採れば終わる）
- 入れない：採取済み・収集品・判定できない品・**伝承録を読んでいない（読んだか確かめられない）伝説の品**（GBR は伝承録を見ずに採集点の前で待ち続けるため）・ほかの有効なリストにある品・所持数が分からない品

**ボタン**

| ボタン | 動き |
|---|---|
| Auto-Gatherに追加 | チェックした帯のリストを作る。**この機能のリストだけ**を書き換え、ほかの機能のリストには触らない |
| 再解析 | 採取履歴を読み直す |
| 完了分を整理 | GBR が止まっているときだけ。リストから採取済みの品を外す |
| Auto-Gatherに停止 | GBR の自動採集を止める（ベンチャー回収の見張りも止める） |

GBR の自動採集中は「Auto-Gatherに追加」を押せません（橙色で「採取中につき操作を受け付けられません」）。チェックは自動採集中も変えられます。

## 6. 全素材の補充

採掘・園芸 × Lv 帯の品を、帯ごとに決めた数ずつ採るリストを作ります。

**数の決め方**（帯ごとに選ぶ）

| 方式 | 目標 |
|---|---|
| 数（既定 100・1〜9999） | 「Auto-Gatherに追加」を押した時点の所持数（本人の鞄）＋数 |
| 希望所持数（チェック） | 鞄とリテイナーの合計がその数になるまで（リテイナーの数は Allagan Tools で読む） |

- 目標は品ごとに覚えます。リストを作り直しても同じ目標を使います（採るほど目標が逃げないため）
- 帯にチェックが入っている間は、数と希望所持数を変えられません（外して変えて入れて押す）
- 入れない品：収集品・地図・イシュガルド復興用・本人のレベルが足りない品・伝承録を読んでいない伝説の品（伝承録を読むと画面には数秒で出ます。リストには次に「Auto-Gatherに追加」を押したときに入ります）
- 帯に乗せると「品：所持X → Y個まで」（希望所持数なら「鞄B＋リテイナーR → N個まで（あと D個）」「足りているので採りません」）が出ます
- ボタンは「Auto-Gatherに追加」「所持数・採取情報を再確認」「Auto-Gatherに停止」。自動採集中は追加を押せないのは §5 と同じです

**§5・§6 に共通の決まり**

- 未採取品の採取と補充の「Auto-Gatherに追加」は**別物**です。押した機能のリストだけを書き換えます
- 設定はキャラクターごとに保存します。**画面に出るのはログイン中のキャラクターのタブだけ**です（別のキャラクターでログインすると、そのキャラクターの保存内容が出ます）
- ログインしたとき、そのキャラクターの「反映した帯」（最後に Auto-Gatherに追加 を押したときのチェック）でリストを作り直し、別のキャラクター用のリストは GBR から外します
- 利用者が GBR の画面で手で足した品・無効にした品は覚えておき、作り直しても戻します
- GBR が採集中に書き換えが要るときは、GBR を止めずに待ちます（キャラクター替えなどのときだけ、採集の切れ目で止めて書きます）

## 7. 霊砂・クリスタル

欲しい霊砂、またはクリスタル・クラスターを選び、目標の数まで、原料（刻限の収集品）を採って精選させます。

**使い方**：欲しいものにチェックを入れ、数を決めて（初期値：霊砂 100・クリスタル 1000）「Auto-Gatherに追加」を押す → GBR の自動採集を ON。霊砂とクリスタルは同時に登録できます（それぞれ 1 つずつ。止めるのも別々）。

**動き**

1. 押したとき、GBR の設定を 3 つ変えます（変える前の値は保存し、止めたら戻します）
   - 詳細 → 精選を使う：ON
   - 詳細 → いつも全部精選する：ON
   - 詳細 → 品目の並べ方：なし（リストの上から順に採らせるため）
2. 原料を各 200 個で並べたリスト `GBRHelper_霊砂`（または `GBRHelper_クリスタル`）を有効で作り、**Auto-Gather の一番上**に入れます
   - 原料の目標数は「200＋鞄にある原料の通常品の数」です（GBR は通常品も数に入れるので、通常品を持っていても収集品を 200 個分採りに行きます）
   - ほかに有効なリストがあっても作れます。原料が出ている間はほかのリストより先に採り、出ていない間はほかのリストの品を採ります（並べ方「なし」の GBR は、出ている刻限の品をリストの上から採るため）
   - 霊砂とクリスタルの両方を登録すると、霊砂のリストを一番上、クリスタルのリストをその下に置きます（霊砂はその原料からしか作れませんが、霊砂の原料はほぼすべて精選でクリスタル・クラスターも出すため）
   - 登録中に一番上からずれたら（GBR の画面で動かしたなど）、一番上へ戻します
   - いま採れる原料が無い霊砂・属性（レベル・伝承録）は飛ばして、採れる物だけ入れます（チェックは残るので、採れるようになれば次に押したときに入ります）
   - 霊砂：原料のレベルの低い順
   - クリスタル：エオルゼア時間 4 時間ごとの 6 つの枠で、選んだ属性がなるべく満遍なく採れる並びを計算して選びます
3. 自動採集中は 0.5 秒ごとに見張り、
   - 目標の数に届いた物の原料は、リストの中で**無効**にします（使って下回ったら有効に戻す。利用者が手で有効に戻した原料はそれ以降触らない）
   - 鞄にある、選んでいない精選できる収集品（自分のリストで採った品など）も一緒に精選されます（GBR の「いつも全部精選する」）。そのために開始を止めることはしません
   - 原料の収集品があれば、採集の切れ目で精選させます。ただし GBR が次に採る品が未知・伝説の採集点のものなら、出現時間を逃さないよう採集を先にします
   - 精選の前後で原料が減ったかを確かめます
4. 「停止して管理リストを削除」（霊砂・クリスタルそれぞれにあります）でそのリストを消します。もう片方が登録中なら、GBR は止めず、設定もそのまま（採集・精選の切れ目で消します）。最後の登録を止めると、GBR の自動採集を止めてリストを消し、GBR の設定を戻します（利用者が途中で変えた設定は戻しません）

**止まる・押せない条件**

- GBR の自動採集中は「Auto-Gatherに追加」を押せません（橙色の文）。手で採っている最中は押せます
- リストの品・数や GBR の設定が外から変えられたら、止めて知らせます
- 精選の途中で GBR の自動採集を止めたときは、精選の待ちだけを取り消し、リストは残します（再び ON にすれば続きから見張る）

## 8. Crafting Listsから末端素材抽出

Artisan の Crafting Lists を 1 つ選び、作るのに要る素材（GBR で採れる品）を GBR のリストにします。
**中身は GBR 自身の「Artisan から読み込む」と同じ**です（Artisan の `ListMaterials` の結果を使う）。画面のボタンの下にも「※Auto-Gatherタブ内の「Artisanから読み込む」からでも取り込めます」と出します。

- プルダウンの一番上は「--Crafting Listsを選択して下さい--」。Crafting Lists が無いときは、選べない空の行だけが出ます
- 「Auto-Gatherに追加する」で `GBRHelper_製作_（リスト名）` を**有効**で作ります。同じ Crafting List でもう一度押すと置き換えます（リスト名を変えても同じリストとして置き換える）
- GBR で採れない素材は入れず、「GBR で採れない素材 n 品は入れていません」と出します（乗せると品名）
- **伝承録を読んでいないと採れない素材（採集品・魚）も入れません**。「伝承録を読んでいない素材 n 品は入れていません」と出します（乗せると品名）。GBR は伝承録を見ずに採集点の前で待ち続けるためです。伝承録を読んでから押し直すと入ります（押すたびにキャラクターの伝承録を読み直します）。レベルの足りない品は GBR が自分で飛ばします
- 手持ちの完成品・中間素材は差し引きません（GBR の取り込みと同じ）
- GBR の取り込みとの違い：押すたびに増えない（置き換える）・有効で作る・自動採集中は押せない・伝承録を読んでいない品は入れない

---

## 9. GBR に作るリスト

GBRHelper が作るリストは、名前と説明欄の印で見分けます。印の無いリスト（利用者が作ったもの）には触りません。

| 機能 | リスト名の例 | 有効 | リテイナーの在庫を数えるか |
|---|---|---|---|
| ベンチャー未採取品の採取 | `GBRHelper_開放_鉱_Lv1-10_未採取` | 有効 | 数える |
| 全素材の補充 | `GBRHelper_100_鉱_Lv1-10`／`GBRHelper_所持_園_Lv11-20` | 有効 | 数えない（希望所持数はリテイナーの分を引いて渡す） |
| 霊砂・クリスタル | `GBRHelper_霊砂`／`GBRHelper_クリスタル` | 有効 | 数えない |
| Crafting Lists | `GBRHelper_製作_（リスト名）` | 有効 | 数える（GBR の既定と同じ） |

書いたあとは、GBR の保存ファイル（`auto_gather_lists.json`）を読み直し、名前・印・品・数・有効が書いたとおりかを確かめます（ファイルを直接書き換えることはしません）。

## 10. 設定の保存

GBRHelper の設定は、Dalamud の `pluginConfigs/GBRHelper/character_<キャラクターID>.json` にキャラクターごとに保存します。帰還先の宿屋・各機能の選択・日本語表示の有効も、キャラクターごとです。各ゲームはログイン中のキャラクターのファイルだけを書くので、2 つのゲームを同時に動かしても、互いのキャラクターの設定を上書きしません。

GBR Venture Relay の設定（`GbrVentureRelay.json`。帰還先の宿屋など）は、各キャラクターで初めてログインしたときに引き継ぎます。元のファイルは変更・削除しません。

**ほかの動きの補足**

- AutoRetainer が回収後にリテイナー一覧を自分で閉じる設定でも、回収が始まっていて残りが無ければ「成功」と数えます。確かめられない結果は成功に数えません
- Crafting Lists のリストは、GBRHelper が最後に書いた名前と今回の名前のものだけを置き換えます。GBR の「Duplicate List」で作った複製は残します。保存に失敗したあとで Crafting List の名前を変えた場合は、元の名前に戻してからもう一度押してください

## 11. 既知の制限

- **複数のゲームを同時に使う場合**：GBRHelper の設定はキャラクター別ファイルですが、GBR 本体の設定とリストは同じ設定フォルダを使うと共有されます。XIVLauncher をアカウントごとに異なる `--roamingPath`（設定フォルダの指定）で起動し、Dalamud の設定フォルダを分けてください。同じフォルダでの同時利用では GBR のリストが互いの保存で上書きされるため、避けてください。ランチャーの設定は自動変更しません。
- 宿屋は、開始都市の宿屋のクエストを済ませていないと入れません

## 12. コードの地図（読む方へ）

| 場所 | 中身 |
|---|---|
| `CharacterConfigStore.cs` | 本人別ファイル・旧設定移行・安全な保存 |
| `Plugin.cs` | 起動・毎フレームの順番・停止 |
| `Ui/MainWindow.cs`・`Ui/RequiredPlugins.cs` | 画面の枠組み・ベンチャー回収の画面・必要なプラグイン |
| `Features/RelayController.cs`・`BellRunner.cs`・`InnTrip.cs` | ベンチャー回収の状態遷移・呼び鈴・宿屋への移動 |
| `Features/UnvisitedFeature.cs`・`UnvisitedPlan.cs` | 未採取品の採取の画面と、入れる品の決め方 |
| `Features/StockFeature.cs`・`MaterialPlan.cs` | 補充の画面と、目標の決め方 |
| `Features/GatherProfileController.cs`・`ProfileUpdateCycle.cs` | キャラクターごとの保存と、GBR のリストの作り直し |
| `Features/TimedFeature.cs`・`CrystalPlan.cs`・`ReductionWait.cs` | 霊砂・クリスタルの登録・見張り・精選 |
| `Features/ArtisanFeature.cs`・`Ipc/ArtisanListAccess.cs` | Crafting Lists の読み取り |
| `Ipc/GbrAutoGatherListAccess.cs` | GBR のリストの読み書き（リフレクション） |
| `Translation/` | GBR の日本語表示（フック・ID の維持・辞書） |

GBR の自動採集リストや設定を変える IPC は GBR に無いので、リストの作成と設定の変更は GBR 本体の公開メンバーへリフレクションで届いています。自動採集の ON／OFF と通知だけは GBR の IPC を使います。
