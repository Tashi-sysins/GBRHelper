# GBRHelper

GatherBuddyReborn（GBR）の自動採集を便利にする Dalamud プラグイン。
GBR 本体には手を加えず、GBR の自動採集のリスト（Auto-Gather）を作る・GBR の IPC で自動採集を止める／動かす、という形で補助する。

GBR Venture Relay（ベンチャー回収だけのプラグイン）を改名し、機能を足したもの。

## できること

| 機能 | 内容 |
|---|---|
| GBR の日本語表示 | GBR のメイン画面の英語を日本語で表示する（ボタンやタブの動きはそのまま） |
| ベンチャー回収 | 自動採集中にベンチャーが回収できるようになったら、採集の切れ目で宿屋の部屋へ戻って回収し、自動採集に戻る |
| ヤンサの山越え | 自動採集がヤンサで烈士庵とナマイ村のあいだの山と川を越えようとしたら、詰まる前に、行き先に近い方のエーテライトへテレポする |
| ベンチャー未採取品の採取 | 採取手帳でまだ採っていない品（ベンチャーで依頼できるもの）を、Lv 帯ごとに GBR のリストにする |
| 全素材の補充 | Lv 帯ごとに全部の品を N 個ずつ（または鞄＋リテイナーで N 個になるまで）採るリストを作る |
| 霊砂・クリスタル | 欲しい霊砂・クリスタルを目標の数まで、原料を採って精選させる。届いた原料はリストの中で無効にする |
| Crafting Listsから末端素材抽出 | Artisan の Crafting Lists の素材（GBR で採れる品。シャード・クリスタル・クラスターは除く）を GBR のリストにする |

仕様と動きの詳細は [docs/説明書.md](docs/説明書.md)。

## 導入

`/xlsettings` で Dalamud の設定を開き、「Experimental」タブの「Custom Plugin Repositories」に次の URL を足して保存する（日本語表示では項目名が違うことがある）。そのあとプラグインの一覧（`/xlplugins`）から「GBRHelper」を入れる。

```
https://raw.githubusercontent.com/Tashi-sysins/Tashi-sysins-repo/main/repo.json
```

**GBR Venture Relay を使っていた場合は、GBR Venture Relay を外す**（両方入れると回収の処理が二重に動く）。
帰還先の宿屋などの設定は、GBRHelper を初めて起動したときに自動で引き継ぐ。

## 必要なプラグイン

画面の左の一覧の「必要なプラグイン」（青い帯）で、導入されているかを確かめられる（足りなければ数と色で知らせる）。

| プラグイン | どのくらい要るか | 使う機能 |
|---|---|---|
| GatherBuddy Reborn | **必須** | すべて |
| AutoRetainer | 機能によって必要 | ベンチャー回収 |
| Lifestream | 機能によって必要 | ベンチャー回収（宿屋の部屋へ帰る）・ヤンサの山越え（テレポ） |
| vnavmesh | 機能によって必要 | ベンチャー回収（部屋の中で呼び鈴へ歩く）・ヤンサの山越え（経路を読む） |
| Allagan Tools | 機能によって必要 | 全素材の補充（希望所持数）・霊砂・クリスタル（リテイナーの数） |
| Artisan | 機能によって必要 | Crafting Listsから末端素材抽出 |

ベンチャー回収の宿屋は、開始都市の宿屋のクエストを済ませていないと入れない。

## コマンド

| コマンド | 動作 |
|---|---|
| `/gbrhelper`（`/gbh`） | 画面の開閉 |
| `/gbrhelper now` | 次の採集の切れ目で回収へ向かう（精選中は完了後） |

GBRHelper の画面の左上の「GBR の画面を開く」で、GBR の画面を「自動採集」タブで呼び出せる（開いているときは閉じずに自動採集タブへ切り替える）。反対に、GBR の自動採集タブの「Artisan から読み込む」の上の「GBRHelperを開く」で、GBRHelper の画面を呼び出せる。

## 設定の保存

GBRHelper の設定は、Dalamud の `pluginConfigs/GBRHelper/character_<キャラクターID>.json` にキャラクターごとに保存する（帰還先の宿屋・各機能の選択・日本語表示の有効も含む）。画面にはログイン中のキャラクターの分だけを出す。

GBR Venture Relay の設定（`GbrVentureRelay.json`。帰還先の宿屋など）は、各キャラクターで初めてログインしたときに引き継ぐ。元のファイルは変えない・消さない。

## 注意

- **GBR の自動採集中は、各機能の「Auto-Gatherに追加」を押せない**（リストを書き換えると採集が乱れるため）。止めてから押す
- **複数のゲームを同時に動かす場合**：GBRHelper の設定はキャラクターごとのファイルだが、GBR 本体の設定とリストは、同じ設定フォルダを使うと共有され、互いの保存で上書きされる。XIVLauncher をアカウントごとに別の `--roamingPath`（設定フォルダの指定）で起動して、Dalamud の設定フォルダを分ける
- GBRHelper が作るリストは名前と説明欄の印で見分け、印の無いリスト（自分で作ったもの・GBR の「Duplicate List」で複製したもの）には触らない

## ビルド

```
dotnet build -c Release
```

`bin\Release\` に DLL と manifest（`GBRHelper.json`）が出る。両方を Dalamud の devPlugins フォルダへ置く（DLL だけでは一覧に出ない）。

ビルド後に自動で配置したい場合は、環境変数 `GBRH_DEPLOY_DIR` に配置先を指定する（指定が無ければ配置しない）。

```
setx GBRH_DEPLOY_DIR "D:\MyPlugins\GBRHelper\"
```

## 更新履歴

### 0.3.0.13

- 「必要なプラグイン」：足りないプラグインに「インストール」ボタンを足した（Dalamud のプラグインの画面を、そのプラグインの名前で検索した状態で開く）。配布元（カスタムプラグインリポジトリ）が登録されていないときは「配布元を追加」（配布元の URL をコピーして Dalamud の設定の試験的機能を開く）、入っているが止まっているときは「有効にする」（インストール済みの画面を開く）も出す。登録済みかは Dalamud の設定ファイルを読んで確かめる（読むだけ）

### 0.3.0.12

- Crafting Listsから末端素材抽出：シャード・クリスタル・クラスターをリストに入れないようにした（足りなければマーケットボードで買うか精選で補充するため）。入れなかった品は「シャード・クリスタル・クラスター n 品は入れていません」と出す。見分け方は GBR と同じ（品の FilterGroup が 11）
- 「GBR の画面を開く」で、GBR のメイン画面を「自動採集」タブで開くようにした。GBR の画面が開いているときは、閉じずに自動採集タブへ切り替える
- GBR の自動採集タブの「Artisan から読み込む」の上に「GBRHelperを開く」ボタンを置いた（GBR の画面を描くときの ImGui の呼び出しに手を入れる。GBR 本体は変えない）

### 0.3.0.11

- 全素材の補充：ジョブクエストなどの専用品（売買できない品。紅蓮の採掘師の廃霊鉱・軽鋼鉱・蛇紋石・硬拳石、園芸師のワイルドポポト・メークインポポト・ナノリソ・ラールガースタッフ、かんざし素材、野生生物の痕跡、改良用の素材など）をリストに入れないようにした。GBR の目録では普通の採集点の品として載るが、ジョブクエストの品は採集点がクエストの途中にしか出ないので、GBR が採れないまま止まっていた。売買できない採取品は、どれもマーケットに出せずレシピの材料にも使わないので、品番ではなく「売買できない」で見分ける

### 0.3.0.10

- ヤンサの山越えを足した：GBR の自動採集中に、これから進む経路（vnavmesh の経路）が烈士庵とナマイ村のあいだの山と川を通るなら、山の斜面や川で詰まる前に、行き先に近い方のエーテライト（烈士庵・ナマイ村）へテレポし、着いたら自動採集に戻る。vnavmesh の飛行の経路がこの山の尾根やふもとの川で地形を突き抜けて引かれ、そこで詰まるため（GBR は同じエリアの中ではテレポしない）。左の一覧の「ヤンサの山越え」の「有効」（既定 ON）で切り替える

### 0.3.0.9

- 全素材の補充：「希望所持数」の帯で、リテイナーに預けた分が Auto-Gather のリストの数に反映されなかった不具合を直した（例：黄鉄鉱を鞄 0・リテイナー 301 持っているのに、リストは 300 個採る数のままだった）。前はリストを最初に作ったときのリテイナーの数で目標を決めて使い回していた。いまは作るたびに、その時点のリテイナーの数から「希望所持数 − リテイナーの数」を決め直す
- 全素材の補充：「希望所持数」の帯は、GBR の自動採集が止まっている間にリテイナーの数が変わる（預ける・引き出す）か、足りていた品が鞄から減ると、Auto-Gather のリストを自動で作り直すようにした（「Auto-Gatherに追加」を押し直さなくてよい）
- ベンチャー回収：回収でリテイナーの数が変わったとき（ベンチャーの戦利品・AutoRetainer の預け入れ）は、「希望所持数」のリストを作り直してから自動採集へ戻すようにした（預けた分まで採り直さないため。作り直しが 30 秒で終わらなければ、そのまま戻る）
- 全素材の補充：「希望所持数」の帯の吹き出しの「登録している品：○件」を、足りていない品（リストに入る品）だけの数にした（前は「足りているので採りません」の品も数えていた）
- リテイナーの数を Allagan Tools から読む回数を減らした（前は品ごとに何度も読んでいた）。Allagan Tools がまだ前のキャラクターを見ている間は読まない

### 0.3.0.8

- 霊砂・クリスタル：霊砂とクリスタルを同時に登録できるようにした（前は片方を登録している間、もう片方は登録できなかった）。Auto-Gather では霊砂のリストを一番上、クリスタルのリストをその下に置く。止めるのも別々（片方を止めても、GBR は止めずにもう片方を続ける）

### 0.3.0.7

- 霊砂・クリスタル：鞄に、選んでいない精選できる収集品（自分のリストで採った品など）があっても開始できるようにした（前は「対象外の精選可能品を鞄から移してから開始してください」と止めていた。登録中は GBR が鞄の精選できる収集品を全部精選する）
- 霊砂・クリスタル：原料の通常品を持っていても開始できるようにした。リストの原料の目標数を「200＋持っている通常品の数」にする（GBR は通常品も数に入れるため。前は「通常品を鞄から移してから開始してください」と止めていた）
- 霊砂・クリスタル：いま採れる原料が無い物（レベル・伝承録）にチェックが入っていても止めず、採れる物だけ登録するようにした（チェックは残すので、採れるようになれば次に押したときに入る。前は「チェックを外してください」と止めていた）

### 0.3.0.6
