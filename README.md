# GBRHelper

GatherBuddyReborn（GBR）の自動採集を便利にする Dalamud プラグイン。
GBR 本体には手を加えず、GBR の自動採集のリスト（Auto-Gather）を作る・GBR の IPC で自動採集を止める／動かす、という形で補助する。

GBR Venture Relay（ベンチャー回収だけのプラグイン）を改名し、機能を足したもの。

## できること

| 機能 | 内容 |
|---|---|
| GBR の日本語表示 | GBR のメイン画面の英語を日本語で表示する（ボタンやタブの動きはそのまま） |
| ベンチャー回収 | 自動採集中にベンチャーが回収できるようになったら、採集の切れ目で宿屋の部屋へ戻って回収し、自動採集に戻る |
| ベンチャー未採取品の採取 | 採取手帳でまだ採っていない品（ベンチャーで依頼できるもの）を、Lv 帯ごとに GBR のリストにする |
| 全素材の補充 | Lv 帯ごとに全部の品を N 個ずつ（または鞄＋リテイナーで N 個になるまで）採るリストを作る |
| 霊砂・クリスタル | 欲しい霊砂・クリスタルを目標の数まで、原料を採って精選させる。届いた原料はリストの中で無効にする |
| Crafting Listsから末端素材抽出 | Artisan の Crafting Lists の素材（GBR で採れる品）を GBR のリストにする |

仕様と動きの詳細は [docs/説明書.md](docs/説明書.md)。

## 導入

`/xlsettings` で Dalamud の設定を開き、「Experimental」タブの「Custom Plugin Repositories」に次の URL を足して保存する（日本語表示では項目名が違うことがある）。そのあとプラグインの一覧（`/xlplugins`）から「GBRHelper」を入れる。

```
https://raw.githubusercontent.com/Tashi-sysins/Tashi-sysins-repo/main/repo.json
```

**GBR Venture Relay を使っていた場合は、GBR Venture Relay を外す**（両方入れると回収の処理が二重に動く）。
帰還先の宿屋などの設定は、GBRHelper を初めて起動したときに自動で引き継ぐ。

## 必要なプラグイン

画面の左の一覧の「必要なプラグイン」（青い帯）で、導入されているかを確かめられる（足りなければ数と色で知らせる）。

| プラグイン | どのくらい要るか | 使う機能 |
|---|---|---|
| GatherBuddy Reborn | **必須** | すべて |
| AutoRetainer | 機能によって必要 | ベンチャー回収 |
| Lifestream | 機能によって必要 | ベンチャー回収（宿屋の部屋へ帰る） |
| vnavmesh | 機能によって必要 | ベンチャー回収（部屋の中で呼び鈴へ歩く） |
| Allagan Tools | 機能によって必要 | 全素材の補充（希望所持数）・霊砂・クリスタル（リテイナーの数） |
| Artisan | 機能によって必要 | Crafting Listsから末端素材抽出 |

ベンチャー回収の宿屋は、開始都市の宿屋のクエストを済ませていないと入れない。

## コマンド

| コマンド | 動作 |
|---|---|
| `/gbrhelper`（`/gbh`） | 画面の開閉 |
| `/gbrhelper now` | 次の採集の切れ目で回収へ向かう（精選中は完了後） |

GBRHelper の画面の左上の「GBR の画面を開く」で、GBR の画面を呼び出せる（開いているときに押すと閉じる）。

## 設定の保存

GBRHelper の設定は、Dalamud の `pluginConfigs/GBRHelper/character_<キャラクターID>.json` にキャラクターごとに保存する（帰還先の宿屋・各機能の選択・日本語表示の有効も含む）。画面にはログイン中のキャラクターの分だけを出す。

GBR Venture Relay の設定（`GbrVentureRelay.json`。帰還先の宿屋など）は、各キャラクターで初めてログインしたときに引き継ぐ。元のファイルは変えない・消さない。

## 注意

- **GBR の自動採集中は、各機能の「Auto-Gatherに追加」を押せない**（リストを書き換えると採集が乱れるため）。止めてから押す
- **複数のゲームを同時に動かす場合**：GBRHelper の設定はキャラクターごとのファイルだが、GBR 本体の設定とリストは、同じ設定フォルダを使うと共有され、互いの保存で上書きされる。XIVLauncher をアカウントごとに別の `--roamingPath`（設定フォルダの指定）で起動して、Dalamud の設定フォルダを分ける
- GBRHelper が作るリストは名前と説明欄の印で見分け、印の無いリスト（自分で作ったもの・GBR の「Duplicate List」で複製したもの）には触らない

## ビルド

```
dotnet build -c Release
```

`bin\Release\` に DLL と manifest（`GBRHelper.json`）が出る。両方を Dalamud の devPlugins フォルダへ置く（DLL だけでは一覧に出ない）。

ビルド後に自動で配置したい場合は、環境変数 `GBRH_DEPLOY_DIR` に配置先を指定する（指定が無ければ配置しない）。

```
setx GBRH_DEPLOY_DIR "D:\MyPlugins\GBRHelper\"
```
